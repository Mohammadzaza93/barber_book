# BarberBook — لوحة تحكم صاحب الصالون

تطبيق Flutter **داخلي فقط** لإدارة صالون الحلاقة من قبل صاحب الصالون (أو الموظفين).

**لا توجد واجهة للعملاء داخل التطبيق.**  
الحجز الخارجي يتم عبر **رابط Google Form** (أو أي رابط حجز خارجي) يشاركه صاحب الصالون مع العملاء.

📖 **دليل الاستخدام الكامل (عربي):** [docs/USER_GUIDE_AR.md](docs/USER_GUIDE_AR.md)

---

## لمن هذا التطبيق؟

- صاحب الصالون
- المدير / الموظفين (حسب الصلاحيات)

**ليس** للعملاء. العملاء يحجزون من خلال الرابط الخارجي فقط.

---

## المميزات (لوحة التحكم)

- تسجيل دخول + معالج إعداد صالون جديد
- لوحة تحكم بإحصائيات ورسوم بيانية وتحليلات ذكية
- إدارة المواعيد: إنشاء / تعديل / إلغاء / تأكيد / حالات متعددة (بما فيها لم يحضر)
- إدارة الخدمات والحلاقين وساعات العمل
- خصومات وعروض داخلية
- مالية ومحاسبة موحّدة (وارد الزبائن + بقشيش + نفقات + تصدير PDF)
- تقييمات العملاء
- تقارير شهرية وأداء
- أدوات أعمال: عملاء موسّعون، ولاء، كراسي + طابور حيّ + دفع عند الإنهاء
- مخزون مع حركات وتنبيهات إعادة طلب
- إعدادات الصالون + **رابط Google Form** مع مشاركة ونسخ وQR
- عربي / إنجليزي (RTL) + مظهر داكن

---

## الحجز للعملاء

1. أنشئ Google Form (أو أي أداة حجز خارجية).
2. الصق الرابط في **الإعدادات → رابط الحجز**.
3. شارك الرابط أو رمز QR من داخل التطبيق.

التطبيق لا يستقبل حجوزات مباشرة من واجهة عملاء.

## التشغيل (للمطوّر)

