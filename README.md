# BarberBook — لوحة تحكم صاحب الصالون

تطبيق Flutter **داخلي فقط** لإدارة صالون الحلاقة من قبل صاحب الصالون (أو الموظفين).

**لا توجد واجهة للعملاء داخل التطبيق.**  
الحجز الخارجي يتم عبر **رابط Google Form** (أو أي رابط حجز خارجي) يشاركه صاحب الصالون مع العملاء.

---

## لمن هذا التطبيق؟

- صاحب الصالون
- المدير / الموظفين (حسب الصلاحيات)

**ليس** للعملاء. العملاء يحجزون من خلال الرابط الخارجي فقط.

---

## المميزات (لوحة التحكم)

- تسجيل دخول + معالج إعداد صالون جديد
- لوحة تحكم بإحصائيات ورسوم بيانية
- إدارة المواعيد: إنشاء / تعديل / إلغاء / تأكيد / حالات متعددة
- إدارة الخدمات والحلاقين وساعات العمل
- خصومات وعروض داخلية
- نفقات + مالية ومحاسبة (صناديق، تسويات، مبيعات يومية)
- تقييمات العملاء (يدوياً أو من مصادر خارجية)
- تقارير شهرية وأداء
- أدوات أعمال: معرض أعمال، ولاء داخلي، كراسي، طابور، مدفوعات
- إعدادات الصالون + **حقل رابط Google Form / رابط الحجز** مع مشاركة ونسخ وQR
- عربي / إنجليزي (RTL)

---

## الحجز للعملاء

1. أنشئ Google Form (أو استخدم Google Calendar appointment slots أو أي أداة).
2. الصق الرابط في **الإعدادات → رابط الحجز (Google Booking URL)**.
3. شارك الرابط أو رمز QR مع العملاء من داخل التطبيق.

التطبيق لا يستقبل حجوزات مباشرة من العملاء عبر الإنترنت.

## المتطلبات

- Flutter SDK (3.27 أو أحدث) مع Dart 3.x
- مشروع Firebase (Authentication + Firestore + Storage)
- `flutterfire_cli`

## التشغيل

```bash
flutter pub get
flutterfire configure   # مرة واحدة لإنشاء firebase_options.dart
flutter gen-l10n
flutter analyze
flutter run
```

## الأمان

قواعد Firestore وStorage مقفلة: الوصول فقط لصاحب الصالون والأعضاء المصرح لهم.
لا تفتح `allow read, write: if true`.

```bash
firebase deploy --only firestore:rules,storage
```
